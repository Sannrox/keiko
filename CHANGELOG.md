## [0.1.0] - 2026-11-27

First published box. Tag `v0.1.0` publishes `ghcr.io/sannrox/keiko:v0.1.0`
for linux/amd64 and linux/arm64.

Install without a checkout with `deploy/tenkai.toml` on a container host, or
`deploy/kubernetes/tenkai.toml` (`kubernetes-inprocess`) beside a consumer.
The host product reads `compose.yaml` from the image. Uninstall keeps
volumes. The Kubernetes product uses Service names `keiko` and `keiko-db`;
create Secret `keiko-tls` first (`scripts/kube-tls.sh`). From a checkout,
`pnpm up` or `pnpm box` still runs the box locally.

### Added

- Seed-deterministic logistics ERP: six tables (customers, orders, shipments,
  stops, exceptions, credits) with mixed status spellings, a nullable foreign
  key, two date formats in one column, and soft deletes.
- Portal `/portal/v1`: bearer token, cursor pagination, and one idempotent
  booking write (`201` create, `200` replay, `409` reuse, `404` unknown
  carrier or shipment). A new booking sets `shipments.carrier_id` in the same
  transaction.
- Control: five switches (`slowPageMs`, `overlapPages`, `dropWriteResponse`,
  `renamedColumn`, `rateLimitSeconds`) and an explicit activity clock.
- Truth: per-table row counts and checksums, plus a compare scorecard
  (missing, extra, different).
- Postgres 17 with TLS, a change-stream publication over every table, and a
  read-only `connector` role.
- Compose box: throwaway TLS authority, seed-if-empty, HTTPS server.

### Security

- Default portal token and database password are rehearsal fixtures.
- The `connector` role can read and replicate; it cannot write.
- Compose publishes on loopback; the image listens on all interfaces inside
  the network.
